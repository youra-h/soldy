# Таблица на React

Таблица soldy на адаптере React рядом с таблицами библиотек React. Стенд, условия сравнения и
методика — [`README.md`, «Таблица»](README.md#таблица); история замеров до 2026-10-25 —
[`table.md`](table.md).

## 2026-10-25 — React, на равных

[869fhddhx](https://app.clickup.com/t/869fhddhx). soldy — `main` на `c3e7d275c`, в условиях
сравнения: `react:soldy+fit=none+width=3248+track`. 5000 строк × 20 колонок, 3 прогона, медиана;
время — в секундах до успокоения кадров.

```bash
npm run bench -- 5000 3 react:soldy+fit=none+width=3248+track,react:mui,react:mantine,react:plain,react:shadcn
```

### Вывод

- Среди библиотек soldy быстрее по всем действиям, кроме размонтирования, и рисуется вровень с
  MUI. По памяти — между Mantine (166 МБ) и MUI (277 МБ).

  компонент Radix; рендер и память — вдвое больше.
