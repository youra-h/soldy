# Установка — Angular

Стенд и методика — [README.md](README.md). Проект — `tools/install-smoke/projects/angular`
(`ng new` со строгими настройками), бюджет `initial` нового проекта — предупреждение 500 КБ,
ошибка 1000 КБ.
