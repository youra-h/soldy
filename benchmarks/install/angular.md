# Установка — Angular

Стенд и методика — [README.md](README.md). Проект — `tools/install-smoke/projects/angular`
(`ng new` со строгими настройками), бюджет `initial` нового проекта — предупреждение 500 КБ,
ошибка 1000 КБ.

Node 24.20.0.

SSR, порог прогона остаётся 2 МБ. Остальное, что весит только у Angular, — объявления выходов и

каждой поверхности, и 21 выход, общий для всех 23 поверхностей, — это 20,7 КБ повторов. Рычаг,
который закрывает перебор, — лист темы: 355,7 КБ на любой странице, и странице из шести
компонентов нужна примерно половина (869fn397y).
