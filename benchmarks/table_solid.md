# Таблица на Solid

Таблица soldy на адаптере Solid рядом с таблицами библиотек Solid. Стенд, условия сравнения и
методика — [`README.md`, «Таблица»](README.md#таблица).

## 2026-10-25 — Solid, первый замер

[869fhddhx](https://app.clickup.com/t/869fhddhx). soldy — `main` на `c3e7d275c`, в условиях
сравнения: `solid:soldy+fit=none+width=3248+track`. solid-js 1.9.17. 5000 строк × 20 колонок, 3
прогона, медиана; время — в секундах до успокоения кадров.

```bash
npm run bench -- 5000 3 solid:soldy+fit=none+width=3248+track,solid:aggrid,solid:plain,solid:tanstack,solid:kobalte
```

### Библиотеки

Готовой таблицы с выбором и сортировкой у Solid почти нет: Kobalte, Ark UI и Park UI таблицы не
дают, SUID и Hope UI заброшены, Simple Table (`@simple-table/solid`) из стенда снята — сортировка
заголовком в ней не сработала ни кликом из кода, ни кликом мыши, да и рисует её ядро на чистом
DOM. Остался AG Grid — официальный адаптер `ag-grid-solid`, заброшенный с 2024 года, на ядре
31.1.1.

|                      | **soldy**   | AG Grid 31.1 (`ag-grid-solid`) |
| -------------------- | ----------- | ------------------------------ |
| Первый рендер        | **3,42**    | 5,68                           |
| Память после рендера | **1,28 ГБ** | 1,69 ГБ                        |
| DOM-узлов            | 125 тыс.    | —                              |
| Выделить все         | 0,72        | **0,64**                       |
| Снять выделение      | 0,62        | **0,60**                       |
| Сортировка ↑         | 1,25        | **0,64**                       |
| Сортировка ↓         | **0,97**    | 1,08                           |
| Замена данных        | **3,07**    | ошибка                         |
| Размонтирование      | **0,47**    | —                              |
| Память после снятия  | **1,8 МБ**  | —                              |

AG Grid — один прогон: на замене данных Solid бросает `Error` своей защиты от зацикливания (больше
миллиона обновлений в одном пакете) — `ag-grid-solid` обновляет сигнал каждой из 105 тыс. ячеек
разом. Остальные прогоны после ошибки не шли (`run.mjs`).

### Вывод

- **Адаптер Solid — провал по памяти и рендеру, худший из адаптеров.** Та же таблица на Vue —
  296 МБ и 1,68 с (`table_vue.md`), на Solid — 1,28 ГБ и 3,42 с, замена данных — 3,07 с против
  1,22 с. Голый Solid на этой разметке — 77 МБ, ядро soldy без проводки — 56 МБ: проводка строки
  на Solid стоит около 245 КБ против 48 КБ на Vue.
- Выделение у soldy — как у Vue, 0,72 с: провал не в действиях, а в сборке строк.
