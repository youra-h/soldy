## 2026-10-29 — долгая сессия

[869fmdbem](https://app.clickup.com/t/869fmdbem). soldy — ветка `task/869fmdbem-pages-soak` на `48d985bd9`; методика — [`README.md`](README.md), «Долгая сессия». Шесть платформ шли одним прогоном, параллельно, своим браузером каждая, с одним зерном: переходы и решения в них у платформ одни и те же.

```bash
npm run soak -- --minutes 60 --seed 20261029
npm run soak -- --pages leak --minutes 1 --every 5 --seed 20261029
npm run soak -- --fw webc --seed 20261029 --replay 1950-1999
npm run soak -- --fw vue,webc --seed 20261029 --replay 5800-5849
```

Chromium 156.0.8078.4, час без перезагрузки после прогрева: 6655 переходов — страница наугад из 34 и `all`, 1–50 копий, сценарий на 1–10 из них, — 169 096 смонтированных копий, 60 890 действий пользователя, из них 12 162 пропущено, перед 3105 язык сменился туда и обратно; посреди действия снято 1250 страниц. Осевший замер пустой страницы — каждые 50 переходов, 135 замеров.

| Замер      | После прогрева | Через час | Наклон за сессию |
| ---------- | -------------: | --------: | ---------------: |
| Куча, МБ   |          11,64 |     13,05 |  0,13 КБ/переход |
| Компоненты |            103 |       103 |                0 |
| Шины       |              0 |         0 |                0 |
| Узлы       |             29 |        29 |                0 |
| Слушатели  |             13 |        13 |                0 |

Ошибок страницы — 0. Проверка замера — сессия по одной `leak` (вторая команда, минута): за 40 переходов компоненты 103 → 2165, шины 0 → 2062, узлы 29 → 3322, слушатели 13 → 1044, итог — **утечка**.

### Итог

- **Утечек нет**: на всех 135 замерах за час счётчики те же, что после прогрева, до единицы, — и после снятия страницы посреди действия, и после смены языка с открытыми слоями.
- **Куча прибавила 1,4 МБ ступеньками, а не наклоном**: 1,2 МБ за первые 450 переходов — прогрев путей, которых не было в прогреве страниц (пропуски, обрывы, смена языка посреди сценария), — затем ровные участки 12,82–12,84 МБ (переходы 450–700), 12,92–12,99 (750–1950) и после ступеньки +0,3 МБ на переходах 1950–1999 — 13,22–13,34 до конца; последний замер — 13,05. Во второй половине сессии наклон 0,01 КБ на переход.
- **Ступенька приходит один раз и повторением не растёт**: повтор переходов 1950–1999 циклами (третья команда, 2 + 20 циклов) даёт ту же ступеньку +0,26 МБ один раз, на третьем цикле, а следующие 17 циклов куча стоит — −0,6 КБ/цикл, итог «чисто»; повтор 5800–5849 — −6,2 КБ/цикл, «чисто». Путь с утечкой прибавлял бы с каждым повтором; это разовая перемена состояния движка или кэша, что именно — сессия не говорит. Терпимо.
- Замер свою подставную утечку видит. Экземпляров и шин у Web Components в ней вдвое больше, чем у остальных платформ: узел элемента, который держит утечка, держит и экземпляр самого элемента.
