# Замеры производительности

Журналы замеров производительности soldy и сравнения с библиотеками компонентов на разных
фреймворках: сколько стоят рендер, действия и память компонента soldy рядом с тем же
компонентом соседей по экосистеме.

## Замеры

Замер — своя папка: в её `README.md` стенд, условия и методика, рядом — журналы по файлу на
платформу.

| Папка                           | Что меряет                                                                                      | Стенд                                            |
| ------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| [`table/`](table/README.md)     | таблица на 5000 строк рядом с таблицами библиотек соседей; `history.md` — история до 2026-10-24 | [`tools/bench-table`](../tools/bench-table/)     |
| [`pages/`](pages/README.md)     | страницы компонентов: вес десятков копий и утечки по циклам; `report.md` — отчёт для статьи     | [`tools/bench-pages`](../tools/bench-pages/)     |
| [`compare/`](compare/README.md) | страницы компонентов soldy рядом с соседями: вес, монтирование, утечки, размер сборки           | [`tools/bench-compare`](../tools/bench-compare/) |

## Как вести журнал

- Журнал дописывается разделами с датой в заголовке (`## 2026-10-25 — Vue, на равных`), старые
  разделы не переписываются: так видно, что дала каждая правка.
- Замер — папка `benchmarks/<замер>/`, журнал — замер на одной платформе: `<замер>/<платформа>.md`
  (`table/svelte.md` — таблица на Svelte). Новый замер — новая папка со своим `README.md` и строка в
  списке выше; новая платформа — новый файл в папке замера, а не раздел в чужом журнале.
- Стенд, условия и методика, общие для журналов одного замера, описаны в `README.md` его папки один
  раз, а журнал даёт на них ссылку и пишет только своё. Отчёт замера для статьи — `report.md` в его
  папке.
