# Соседи — Angular

Стенд, условия и методика — [README.md](README.md).

## 2026-10-26 — первый прогон

### Участники

- **soldy** — хост превью Angular (`tools/bench-pages`), тема oren, иконки Material, Angular 22.2.3
  без Zone.js.
- **material** — `@angular/material` и `@angular/cdk` 22.2.4, готовая тема `azure-blue.css`,
  `provideNativeDateAdapter()`.
- **primeng** — `primeng` 22.1.4, тема Aura из `@primeuix/themes` 3.0.1 (`providePrimeNG`).
- **zorro** — `ng-zorro-antd` 22.1.2, `ng-zorro-antd.min.css`, `provideNzI18n(en_US)` (по
  умолчанию у библиотеки китайский), `provideNzNativeDateAdapter()`.

Все — одно приложение на участника без Zone.js (`createApplication`), как хост soldy; zone.js не
понадобился ни одной библиотеке. `@angular/animations` никто из трёх не требует. Копии страницы —
в месте одного корневого компонента (`libs/angular/mount.ts`), у soldy корень — с
`so-locale-provider`.

### Матрица

| soldy             | material                                                    | primeng                        | zorro                                     |
| ----------------- | ----------------------------------------------------------- | ------------------------------ | ----------------------------------------- |
| Button            | `matButton`                                                 | `p-button`                     | `nz-button`                               |
| Input             | `matInput` в `mat-form-field`                               | `pInputText`                   | `nz-input`                                |
| CheckBox + Label  | `mat-checkbox`                                              | `p-checkbox` + `label for`     | `label nz-checkbox`                       |
| Switch + Label    | `mat-slide-toggle`                                          | `p-toggleswitch` + `label for` | `nz-switch` в `label`                     |
| Select `editable` | `mat-autocomplete` с фильтром (без стрелки: открывает поле) | `p-autocomplete` с `dropdown`  | `nz-select nzShowSearch` (открывает поле) |
| Tabs              | `mat-tab-group`                                             | `p-tabs`                       | `nz-tabs`                                 |
| Dialog с полем    | `MatDialog.open`                                            | `p-dialog modal`               | `nz-modal`                                |
| Tooltip           | `matTooltip`                                                | `pTooltip`                     | `nz-tooltip`                              |
| Menu              | `mat-menu`, вложенные меню                                  | `p-tieredmenu popup`           | `nz-dropdown` + `nz-menu`, `nz-submenu`   |
| DatePicker        | `mat-datepicker` с кнопкой                                  | `p-datepicker showIcon`        | `nz-date-picker` (открывает поле)         |

Сверено: тексты и данные превью (`COLLECTION_ITEMS`), подменю с подменю, выключенный и «опасный»
пункт, сочетания клавиш. Собрано из частей (пометка): ни у кого нет пунктов-флажков и
переключателей в меню — пункты с `role` и отметкой; подписи групп у Material — текст, у PrimeNG —
выключенные пункты; у NG-ZORRO меню открывается кликом (`nzTrigger="click"`, по умолчанию —
наведение). Пункта с календарём («Срок») у соседей нет — как у страниц React. Подсказка по фокусу
из скрипта у всех трёх не открывается (Material — только с клавиатуры, PrimeNG и NG-ZORRO — только
наведение), действие при этом считается так же, как у soldy.

Сценарии: Escape у соседей шлётся с `keyCode` (`libs/angular/scenarios.ts`) — оверлеи CDK и
соседей проверяют его, а помощник soldy шлёт только `key`; число действий то же. Панель меню
NG-ZORRO открывается через 150 мс даже по клику — помощник ждёт её появления до 30 кадров.
Расхождений числа действий в прогоне нет.

### Наблюдения

- **Вес копии** soldy в Angular в разы выше соседей на каждой странице: кнопка 27,5 КБ против
  3,4–33 КБ, Select 362 КБ против 51–78 КБ, Menu 736 КБ против 47–150 КБ, DatePicker 773 КБ
  против 33–63 КБ, набор `all` ≈3,1 МБ против 0,4–0,65 МБ. Это можно утверждать: копии и данные
  одни, сценарии прошли с тем же числом действий. Разрыв больше, чем у страниц React, — повод
  разобрать проводку адаптера Angular отдельно.
- **Утечки**: у soldy все страницы «чисто». У соседей часто «куча растёт» (порог — втрое выше
  `empty` и не меньше 4 КБ): сильнее всего NG-ZORRO — select 59, menu 48, date-picker 50,
  tabs 29 КБ/цикл. Узлы и слушатели не оседают ни у кого (у zorro menu −1 слушатель — шум).
  Утверждать утечку соседей нельзя: это рост кучи на 20 циклах, а не осевшие счётчики.
- **Размер сборки** у soldy одинаков на любой странице (~305 КБ gzip): точка тянет почти всю
  библиотеку — так же, как у soldy React; дерево по адаптеру и поведению темы не трясётся. На
  одной странице soldy тяжелее всех; в `all` (310 КБ) — легче NG-ZORRO (401 КБ), рядом с PrimeNG
  (295 КБ) и Material (265 КБ).
- **Монтирование** — второстепенно: платформы и участники шли параллельно с прогонами других
  платформ. У soldy Select, Tabs, Menu, DatePicker — 150–250 мс на 50 копий против 25–70 мс у
  соседей.
- PrimeNG печатает предупреждение `[PrimeUI] PrimeUI license is not configured` — в ошибки
  прогона не идёт.
