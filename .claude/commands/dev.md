---
description: Запустить программиста по задаче ClickUp
argument-hint: [task_id]
---

Запусти агента `developer` по задаче ClickUp.

ID задачи: `$ARGUMENTS`

Если ID не указан — сначала сам вызови `clickup_list_by_status` со статусом
`in progress` и возьми **первую свободную** задачу из очереди — с `busy: false`
и `blocked: false`. Очередь уже отсортирована: по приоритету `urgent` → `high` →
`normal` → `low` (без приоритета — как `normal`), внутри приоритета от старых к
новым; не пересортировывай её. Задачи с `busy: true` уже в работе у другой
роли, с `blocked: true` ждут незакрытые задачи из `waitingOn` — их не бери.
Тогда:

- свободных задач нет — скажи об этом и остановись, агента не запускай;
- задач несколько — назови мне взятую с её приоритетом и перечисли остальные;
  занятые пометь «в работе», заблокированные — «ждёт» и кого.

Перед запуском агента проверь `git status` и текущую ветку:

- дерево чистое — запускай;
- дерево грязное, но ты **на ветке задачи** (`task/<task_id>-*`) — это
  незаконченная работа программиста с прошлого захода. Запускай: он продолжит
  с этого места. Скажи мне, что это продолжение, а не первый заход;
- дерево грязное **вне** ветки задачи — остановись и скажи мне. Программист не
  должен коммитить чужие изменения.

Проверь также, что `gh` доступен (`gh auth status`) — без него агент дойдёт до
создания PR и упадёт, потратив весь заход.

Передай агенту только ID задачи — план он читает сам из комментариев.

Когда агент закончит, покажи мне, в какой статус он перевёл задачу (APPROVED
или PLANNING), ссылку на PR, результат прогона тестов, отклонения от плана и
вопросы для тимлида. Если тесты красные — скажи об этом
первым делом.
