---
description: Запустить программиста на выпуск — поднять версии и собрать CHANGELOG
---

Запусти агента `developer` на выпуск. Задачи ClickUp у выпуска нет.

Перед запуском проверь:

- `git status` — дерево чистое. Грязное — остановись и скажи мне: программист
  переключит ветку, чужие правки поедут в выпуск;
- `gh auth status` — без `gh` агент не откроет PR;
- `git fetch origin && git ls-remote --heads origin "release/*"` — открытой
  ветки выпуска нет. Есть — остановись: прошлый выпуск ещё не влит, назови его
  ветку.

Передай агенту только слово `release`.

Когда агент закончит, покажи мне версию выпуска, ссылку на PR, результат
прогона тестов и разделы CHANGELOG, которые вошли в выпуск. Если выпускать
было нечего — так и скажи. Если тесты красные — скажи об этом первым делом.
