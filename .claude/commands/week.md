---
description: Сводка недели — выпуски и влитые PR за последние семь дней
---

Собери сводку того, что сделано за последние семь дней (или за период из
аргумента: `$ARGUMENTS`, например `2026-10-12..2026-10-18`). Ничего не меняй:
ни файлов, ни задач ClickUp.

1. Выпуски за период: `gh release list` и `gh release view <тег>` — разделы
   CHANGELOG вошедших версий. Тег выпуска библиотеки — `v<версия>`, выпуска
   тем и иконок без неё — тег его первого пакета (`@soldy-ui/theme-base@0.3.1`).
   Выпусков не было — смотри
   `.changeset/*.md` на `origin/main`: это сделанное, но ещё не выпущенное.
2. Влитые PR за период:
   `gh pr list --state merged --search "merged:<с>..<по>" --limit 500 --json number,title,mergedAt,url`.
   PR `Выпуск …` в список не идут — они уже в пункте 1.
3. Сгруппируй по смыслу, а не по PR: компоненты (новое, исправления),
   ломающие изменения с подсказкой, как обновиться, тема, стенд и
   инструменты. Пиши для человека вне проекта: что теперь умеет библиотека,
   без путей к файлам и имён классов. Один пункт — одна строка; похожие PR
   сливай в один пункт.
4. В конце — цифры: выпущенные версии, число влитых PR, число невыпущенных
   changeset'ов.

Выведи сводку в ответе Markdown'ом, чтобы её можно было вставить как есть.
