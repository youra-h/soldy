description: Запустить дизайнера по задаче ClickUp
argument-hint: [task_id]
---

Запусти агента `designer` по задаче ClickUp.

ID задачи: `$ARGUMENTS`

Если ID не указан — сначала сам вызови `clickup_list_by_status` со статусом
`design` и возьми **первую свободную** задачу из очереди — с `busy: false` и
`blocked: false`. Очередь уже отсортирована: по приоритету `urgent` → `high` →
`normal` → `low` (без приоритета — как `normal`), внутри приоритета от старых к
новым; не пересортировывай её. Задачи с `busy: true` уже в работе у другой
роли, с `blocked: true` ждут незакрытые задачи из `waitingOn` — их не бери.
Тогда:

- свободных задач нет — скажи об этом и остановись, агента не запускай;
- задач несколько — назови мне взятую с её приоритетом и перечисли остальные;
  занятые пометь «в работе», заблокированные — «ждёт» и кого.

Дизайнер пишет в репозиторий, как программист. Перед запуском проверь
`git status` и текущую ветку:

- дерево чистое — запускай;
- дерево грязное, но ты **на ветке задачи** (`task/<task_id>-*`) — это
  незаконченная работа с прошлого захода. Запускай и скажи мне, что это
  продолжение;
- дерево грязное **вне** ветки задачи — остановись и скажи мне.

Проверь также `gh auth status` — без него агент не откроет PR.

Передай агенту только ID задачи — постановку он читает сам из ленты.

Когда агент закончит, покажи мне, в какой статус он перевёл задачу (APPROVED
или PLANNING), ссылку на PR (если открыт), выжимку спецификации — структура,
состояния, иконки, цвета, — результат прогона и что он заметил на скриншотах.
Если прогон красный — скажи об этом первым делом.
