Запусти агента `techlead` по задаче ClickUp.

ID задачи: `$ARGUMENTS`

Если ID не указан — сначала сам вызови `clickup_list_by_status` со статусом
`planning` и возьми **первую свободную** задачу из очереди — с `busy: false`
(список отсортирован от старых к новым). Задачи с `busy: true` уже в работе у
другой роли, их не бери. Тогда:

- свободных задач нет — скажи об этом и остановись, агента не запускай;
- задач несколько — назови мне взятую и перечисли остальные; занятые пометь
  «в работе».

Передай агенту только ID задачи — контекст он собирает сам.

Когда агент закончит, покажи мне, в какой статус он перевёл задачу, краткую
выжимку плана (или вопросы ко мне, если OVERVIEW) и отметь, писал ли он
что-нибудь в репозиторий и заводил ли новые задачи.
