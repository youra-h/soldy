Плагины и проводка коллекций находят соседние расширения охранниками контракта, а не чтением движка без типа; у ListBox для этого появился охранник `listOf`. Поведение не меняется. Ломающее для наследников `TListNavigationPlugin`: `shown()` отдаёт массив только для чтения — копию для правки снимайте сами (`[...this.shown()]`); элемент своего списка наследник называет вторым параметром типа базы (по умолчанию `IControl`).
