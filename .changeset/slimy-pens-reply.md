Ядро: сортировка строк таблицы по колонкам. Расширение `sort` коллекции строк упорядочивает показанное (`batch.shown`) и не трогает порядок данных (`batch.items`): снятая сортировка возвращает строки в порядок данных, равные остаются в нём при любом направлении. Состояние — `sort`, колонки и направления по приоритету (`{ field, direction }`), проп фасада `TTableCollectionFacade` с событием `change:sort`: сверка по содержимому, тот же список, собранный заново, — не смена. Режим `sortMode` — `single` (другая колонка заменяет прежнюю) или `multiple` (новая встаёт последней по приоритету); команда пользователя `toggleSort(field)` ведёт колонку по циклу «по возрастанию → по убыванию → снята». `presorted` — строки приходят упорядоченными, например сервером: состояние и события есть, строки таблица не переставляет. У колонки `TTableColumn` — `sortable` (кнопка сортировки в заголовке, по умолчанию нет) и `compare` — своё сравнение записей; по умолчанию сравниваются значения поля: числа — по величине, текст — по языку таблицы (`locale` у `TTable`, по умолчанию `en-US`) с числами внутри строк, пустые — в конце. В наборы колонки расширение пишет `data-sort` и `data-sort-priority` для темы, `aria-sort` — только первой по приоритету. Ушедшая колонка снимает свою сортировку, скрытая — оставляет.
