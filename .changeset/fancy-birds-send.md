Повторный рендер родителя больше не откатывает значение, которое пользователь успел поменять, если оно задано литералом массива. Литерал, который фреймворк пересоздаёт на каждом проходе (`value={['a', 'b']}` в React), связка считала новым значением и писала в компонент заново: так, например, возвращался к разметке выбор Select с `mode="multiple"`. Теперь прошлое значение из разметки сверяется по содержимому — массивы и простые объекты поверхностно, тем же правилом, что уже сверяет запись в ядро. Массив новых объектов (`items` литералом) по-прежнему считается сменой; дельта Angular и Web Components по-прежнему доходит до ядра командой.
