Web Components: разметка страницы, ожившая при подключении пакета, собирается в порядке документа во всех браузерах, включая Safari с полифилом. Пункты меню разных видов стоят по порядку, стрелки и набор по буквам ходят порядком экрана, группа внутри подменю даёт ключ своим пунктам. Сборка больше не зависит от порядка регистрации элементов
