Компонент над тем же `ctrl`, перемонтированный в другом месте, больше не трогает прежний посреди чужого рендера: сборка над инстансом атомарна для остальных его монтирований. Их состояние и уведомления приходят после сборки — уведомление получает и прежний, снятый тем же проходом, один раз; отменяемые события (`*:before`) уходят сразу, и `preventDefault` работает, как вне перемонтирования. В React смена `key` над внешним `ctrl` больше не печатает «Cannot update a component while rendering a different component», в том числе из обработчиков, меняющих состояние родителя, а в `Suspense` — не зацикливается: повтор рендера берёт id монтирования отброшенной сборки.
