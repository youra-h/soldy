Поведение темы (`@soldy-ui/theme-oren/setup`) уезжает собранным ESM с декларациями, как остальные пакеты: экспорт ведёт в `dist/setup`, исходники наружу не отдаются. Поверхность прежняя. Пакет собирает `npm run build` из корня; отдельный скрипт `build:css` собирает только CSS — он нужен там, где соседи ещё не собраны (первый шаг CI, `npm run test:layout`).
