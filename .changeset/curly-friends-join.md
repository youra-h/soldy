Монтирование компонента быстрее: участника, который публикует событие, обмен находит картой по полному имени за один проход, а не перебором всех пропсов и триггеров на каждое событие, а полное имя (`TName.getName()`) склеивается один раз на объявление. Первый рендер таблицы на 5000 строк во Vue — 2,5 с вместо 2,9 с, замена её данных — 4,1 с вместо 4,6 с. Поведение не изменилось.

Ломающее — для тех, кто собирает обмен сам: `TMember.publishes(fullName)` заменён перечнем `TMember.published()` — явные события участника, затем триггеры его пропсов.
