Компонент над тем же `ctrl`, перемонтированный в другом месте, больше не перерисовывает прежний посреди чужого рендера: сборка над инстансом атомарна для остальных его монтирований, их состояние перечитывается после неё. В React смена `key` над внешним `ctrl` больше не печатает «Cannot update a component while rendering a different component», а в `Suspense` — не зацикливается: повтор рендера берёт id монтирования отброшенной сборки.
