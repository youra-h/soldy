Solid: подпись Label и поля Input, CheckBox и Switch — по разметке Vue, с тестами один к одному с React. Label рисует корень по `tag` (по умолчанию `label`): контрол — содержимым, текст — слотом `content` или пропом `text`; пустой текст не рисуется, и обёртку прячет `:empty` темы. У поля атрибуты потребителя делятся, как во Vue и React: класс и стиль — корню, всё остальное — `<input>` поверх его `aria`, туда же и `ref` потребителя (`toRootForward`, `toControlAttrs`). Тип атрибутов поля — `TFieldAttributes`: атрибуты `<input>` без того, что поле ведёт само (`checked`, `prop:indeterminate`, `readOnly`); `UseDomProps` и `TDomAttributes` принимают тип атрибутов последним параметром. Отметку Solid пишет свойством узла, «выбрано частично» — явно свойством (`prop:indeterminate`): его тип адаптер дописывает в `JSX.ExplicitProperties` Solid. Текст поля — свой `ref` поля `fieldText`: в узел, только когда текст разошёлся с узлом, поэтому набор не переписывает поле и браузер не перестаёт проверять `minlength`; на сервере текст уходит атрибутом `value`. Отметка CheckBox без слота — `<svg>` иконки по роли (`roleIcon`). Кнопка очистки Input берёт имя из локали поддерева: у Solid это первый компонент со строками.
