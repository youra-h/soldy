Table в React: выбор строки больше не перерисовывает ячейки. Строки (`Table.Row`) и их ячейки стоят под границей перерисовки адаптера — `withRenderBoundary` из `@soldy-ui/react`, обёртка `memo` без своего сравнения: таблица перерисовывается на каждый выбор, а строку перерисовывают только её собственное состояние и новые входы, ячейки — только новые ячейки, их набор или новый слот `cell`. «Выбрать все» на тысячах строк больше не зовёт слот `cell` на каждую ячейку. Граница держит, пока приложение отдаёт слот `cell` одним и тем же объектом: стрелка в разметке перерисует ячейки на каждый рендер приложения, но не на выбор.

Компоненты React больше не перерисовываются второй раз сразу после монтирования: адаптер отдаёт React состояние так, что значение, то же по содержимому, остаётся прежним объектом. Раньше повторное чтение при подписке давало новые объекты составных значений, и строка таблицы при монтировании рисовалась дважды — со всеми ячейками и слотом `cell` на каждую.
